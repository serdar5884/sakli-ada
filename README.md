# Saklı Ada

Three.js ile yapılmış düşük poligonlu 3B balıkçılık ve macera oyunu (Türkçe arayüz).

- Olta balıkçılığı, dalış, zıpkın, yay ile avlanma, görevler, mağaza, tekne
- Dağlara tırmanış, gece/gündüz, doğa sesleri

## Oynamak
Tarayıcıda: https://serdar5884.github.io/sakli-ada/

`index.html` tek dosyalık, bağımsız bir sürümdür; indirip doğrudan tarayıcıda da açabilirsin.

## Geliştirme
```
npm install
./build.sh      # dist/index.html üretir
```
Kaynak kod `src/` klasöründedir.
